Three traps, all measured

  • Steel #6E6E6E is the lightest gray that may carry text on white. It measures 5.10:1.
  • Mute #9A9A9A is never text, at any size. It measures 2.81:1 on white.
  • Black is a band, a title or a divider. It is never the page a document is read on. On black use #D6D6D6 for body text and #9E9E9E for captions.

Type

Montserrat throughout. There is no secondary typeface and no italic. The four weights are in fonts/static/, and the variable file is in fonts/.

Display caps

Heading in sentence case

Body copy sits at this size and weight. Short declarative sentences, active verbs, nothing before the point.

Caption and metadata sit here.

Do not

  • Stretch, squash, skew or rotate the logo.
  • Recolor it. Pick the file that matches the background.
  • Color anything but the wedge.
  • Force EDGE to full black or full white. It is gray.
  • Add a drop shadow, glow, outline or gradient.
  • Split the block mark from the wordmark in the horizontal lockup.
  • Merge the mark with a partner’s logo into one shape.
  • Put two Collective Edge lockups on one page.
  • Render it below the minimum sizes above.
